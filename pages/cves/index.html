BOLA / IDOR · GraphQL API

An Insecure Direct Object Reference (IDOR) / BOLA vulnerability was discovered in the GraphQL API. By manipulating object IDs in mutation requests, authenticated users could access and modify data belonging to other users without authorization. This issue was responsibly disclosed and successfully patched by the maintainers in version v1.3.
